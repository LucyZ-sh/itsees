# Itsees 0.1.0-beta.5

Somewhere out there, a wide world is waiting. Let it wander ahead — and bring the wonder home.

## What changed

- Polished English across the App and desktop-pet cards, aligned key product terms, and removed mixed Chinese/English UI fragments.
- Fixed route selection, travel-pack item selection, carousel navigation, and collection filtering so every action targets the item the user chose.
- Restored double-click expansion for the companion and cards, and added the Phase 1-to-Phase 2 handoff animation.
- Improved desktop-pet and background rendering sharpness and tightened card sizing around real bilingual content.
- Fixed English postcard counts, music-cache labels, status copy, date formatting, and first-run language accessibility labels.
- Upgraded `tar` to a patched release and re-verified Electron sandboxing, repository boundaries, assets, plugin runtime, website metadata, and travel-engine behavior.

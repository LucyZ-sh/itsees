A short note before departure

Installation guide

Itsees currently supports Apple Silicon Macs. The whole setup takes only a moment.

Download
  1. 01

    Download the DMG from this official page.

  2. 02

    Open the DMG, then drag Itsees into the Applications folder.

  3. 03

    Open Itsees. If macOS stops the first launch, go to System Settings → Privacy & Security, choose Open Anyway, then confirm Open.
